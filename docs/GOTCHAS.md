# Gotchas

Rules learned from owner corrections. One rule per entry: the mistake pattern, then the rule that prevents it.

- **A polished derived page lacked review controls while its source documents supported comments.** When adding a visual summary, carry the same private comment and provenance journey to each meaningful card, node, and image; verify one point-to-comment interaction in the rendered app.
- **A strong homepage made adjacent campaign sheets feel unfinished.** Apply the same reading hierarchy across every sheet type, then inspect representative person, place, faction, scene, relation, and timeline views at desktop and mobile widths.
