# Gotchas

Rules learned from owner corrections. One rule per entry: the mistake pattern, then the rule that prevents it.

- **A database-backed web workspace kept the campaign away from the GM's own tools.** Campaign data lives in readable files in Git; build checks and exports around them, never a store the GM must open an app to reach.
- **A scene sheet described danger but still required the PDF for every turn.** Put the table-facing situation first, then the labeled map, round procedure, actions, opposition, rewards, and visible source-backed gaps; walk through every round with the PDF closed before calling it runnable.
